# iExif 官网部署说明

压缩包里有：

- `iexif/`：网站文件，整个上传到服务器，作为网站根目录。里面有一个隐藏文件 `.htaccess`，不要漏掉。
- `nginx-iexif.conf`：用 Nginx 时的配置示例。
- `README.md`：本说明。

## 服务器要求

- PHP 8.0 或更高，不需要数据库，也不需要安装任何扩展。
- Apache 或 Nginx 任选一种。
- 一个域名，并开启 HTTPS。服务器在中国大陆时，域名需要先完成 ICP 备案。

## 方式一：宝塔面板（Nginx）

1. 网站 → 添加站点：填写域名，PHP 版本选 8.0 或更高，数据库选“不创建”。
2. 进入站点根目录（默认 `/www/wwwroot/你的域名`），删除面板自动生成的 `index.html` 和 `404.html`，上传压缩包，解压后把 `iexif/` 里的所有文件（包括 `.htaccess`）移到根目录。
3. 站点设置 → SSL → Let's Encrypt，申请证书，然后打开“强制 HTTPS”。
4. 站点设置 → 伪静态，粘贴下面几行并保存：

   ```nginx
   location ^~ /inc/ { return 404; }
   location ~ /\.(?!well-known/) { return 404; }
   location ~ \.(md|log|ini|sh)$ { return 404; }
   location = /robots.txt  { rewrite ^ /robots.php last; }
   location = /sitemap.xml { rewrite ^ /sitemap.php last; }
   ```

5. 站点设置 → 配置文件，然后保存：
   - 找到 `error_page 404 /404.html;`，改成 `error_page 404 /404.php;`。如果这一行前面有 `#`，把 `#` 删掉。
   - 可选：在 `include enable-php-xx.conf;` 那一行下面加一行 `fastcgi_param IEXIF_SITE_URL https://你的域名;`。

## 方式二：Apache（虚拟主机或自己的服务器）

1. 把 `iexif/` 里的所有文件（包括 `.htaccess`）上传到网站根目录。
2. 确认 Apache 启用了 `mod_rewrite`、`mod_headers`、`mod_expires`，并且站点允许 `.htaccess`（`AllowOverride All`）。大多数虚拟主机默认就是这样。
3. 开启 HTTPS。
4. 可选：在 `.htaccess` 最后加一行 `SetEnv IEXIF_SITE_URL https://你的域名`。

## 方式三：Nginx（自己的服务器）

1. 上传到 `/var/www/iexif`：
   `scp -r iexif/ 用户名@服务器:/var/www/`
2. 把 `nginx-iexif.conf` 复制到 `/etc/nginx/conf.d/`，按注释改好域名、证书路径和 `fastcgi_pass`。
3. 还没有证书时，先用 `certbot certonly --webroot -w /var/www/iexif -d 你的域名` 申请。
4. 执行 `nginx -t && systemctl reload nginx`。

## 关于 IEXIF_SITE_URL

它决定分享卡片、sitemap、canonical 链接里使用的网址。不设置也能用，网站会按访问的域名推断；但网站前面有 CDN 或反向代理时，推断可能得到 `http://`，所以建议设置。

## 上线后检查

用浏览器逐个打开，结果应该是：

| 地址 | 应该看到 |
|---|---|
| `https://你的域名/` | 首页，截图正常显示 |
| `/support.php`、`/privacy.php` | 技术支持、隐私政策页 |
| `/?lang=en` | 切换到英文 |
| `/robots.txt`、`/sitemap.xml` | 文本或 XML，里面的网址是 `https://你的域名` |
| `/inc/lang.php`、`/不存在的页面` | iExif 的 404 页 |

然后：

1. 在 App Store Connect 里填写网址：
   - 隐私政策网址：`https://你的域名/privacy.php`。在“App 隐私”页面修改，随时生效。
   - 技术支持网址：`https://你的域名/support.php`。
   - 营销网址：可以填首页。
   技术支持和营销网址属于版本信息，通常要在下一个版本提交时才能修改。在那之前，原来填的地址要保持能打开。
2. 可选：在 Google Search Console 和百度搜索资源平台提交 `https://你的域名/sitemap.xml`。

## 以后更新

改完文件后，重新上传改动过的文件并覆盖即可。改了 `style.css` 时，记得把 `inc/header.php` 里 `style.css?v=` 后面的数字加一，这样访客的浏览器会拿到新样式。
