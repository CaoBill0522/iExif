# iExif 官网

PHP 8.0+，无数据库、无 Composer、无前端构建。页面：首页 `/`、技术支持 `/support.php`、隐私政策 `/privacy.php`，中英双语（`?lang=zh` / `?lang=en`，选择会记在一年有效的 Cookie 里）。

## 本地预览

在项目根目录执行：

```sh
php -S 127.0.0.1:8098 -t web tools/dev-router.php
```

`tools/dev-router.php` 模拟 `web/.htaccess` 的规则（404 页、屏蔽内部文件、robots.txt 和 sitemap.xml），PHP 内置服务器本身不读 .htaccess。

## 部署

运行 `tools/package-site.sh` 生成部署包（`dist/iexif-site-日期.zip`），部署步骤见 `deploy/部署说明.md`。只上传 `web/` 目录里的内容（包括隐藏文件 `.htaccess`），把网站根目录指向它，启用 HTTPS。

建议设置两个环境变量：

| 变量 | 作用 | 默认 |
|---|---|---|
| `IEXIF_SITE_URL` | 正式地址，例如 `https://iexif.example.com`，用于 canonical、hreflang、分享卡片、sitemap | 按请求域名推断 |
| `IEXIF_SUPPORT_EMAIL` | 联系邮箱 | caojiacheng38@gmail.com |

### Apache

`web/.htaccess` 已包含：404 页、屏蔽 `inc/` 和 `.md` 等内部文件、robots.txt / sitemap.xml 重写、安全头（含 CSP）、静态资源缓存和压缩。需要启用 `mod_rewrite`、`mod_headers`、`mod_expires`。

### Nginx 等效配置

```nginx
root /var/www/iexif/web;
index index.php;
error_page 404 /404.php;

location ^~ /inc/ { return 404; }
location ~ /\.(?!well-known/) { return 404; }
location ~ \.(md|log|ini|sh)$ { return 404; }
location = /robots.txt  { rewrite ^ /robots.php last; }
location = /sitemap.xml { rewrite ^ /sitemap.php last; }

location ~ \.php$ {
    try_files $uri =404;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_param IEXIF_SITE_URL https://iexif.example.com;
    fastcgi_pass unix:/run/php/php-fpm.sock;
}

location ~* \.(css|js|jpg|png)$ { expires 30d; }

add_header X-Content-Type-Options nosniff always;
add_header Referrer-Policy strict-origin-when-cross-origin always;
add_header Content-Security-Policy "default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; base-uri 'self'; form-action 'self'; frame-ancestors 'self'" always;
```

上线后把隐私政策和技术支持的完整 HTTPS 地址填进 App Store Connect，并在 Google Search Console 提交 `/sitemap.xml`。

## 内容维护

- `web/inc/strings.php`：全部中英文文案（功能、FAQ、隐私政策）
- `web/inc/lang.php`：App Store 链接、联系邮箱、更新日期、网站地址
- `web/assets/img/shots/`：真实 App 截图，命名为 `{语言}_{编号}_{名称}.jpg`，同名加 `_dark` 的是深色模式版本，页面会按访客的系统深浅色自动切换（`shot_img()`，在 `inc/lang.php`）。手机截图 560×1217，iPad 1200×1600。
- `web/assets/img/badge/`：苹果官方 App Store 徽章（中英文、黑白两色），来自 tools.applemediaservices.com。按苹果规范不得修改图形、颜色或文字，显示高度不低于 40px；浅色背景用黑色，深色背景用白色。使用徽章时页脚必须保留 Apple 商标声明（`footer_note`）。
- `web/assets/img/og-zh.jpg` / `og-en.jpg`：1200×630 分享卡片
- 导航：宽度 ≤900px 时收进右上角的汉堡菜单（`<details class="menu">`，不开 JavaScript 也能用；`assets/js/site.js` 负责点外部 / Esc / 点链接后收起）
- `web/assets/css/style.css`：样式（改动后把 `inc/header.php` 里 `style.css?v=` 的数字加一，让浏览器更新缓存）

隐私政策里关于网络的措辞：照片元数据编辑在本机完成，但 Apple 地图、iCloud 照片下载、系统分享可能使用网络，不要写成“App 完全不联网”。价格以 App Store 为准。
