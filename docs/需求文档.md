# iExif 需求文档

- 名称：iExif（工程和 Bundle ID 沿用 ExifEditor / cn.oxoz.exifeditor）
- Bundle ID：`cn.oxoz.exifeditor`
- 技术栈：Swift + SwiftUI，最低 iOS 17，iPhone + iPad 通用
- 语言：简体中文 + 英文（String Catalog）
- 发布：App Store，免费，无内购

## 1. 可编辑字段

| 分组 | 字段 |
|---|---|
| 设备 | Make、Model、Software |
| 镜头 | LensMake、LensModel、FNumber、FocalLength、FocalLengthIn35mmFilm |
| 拍摄参数 | ExposureTime、ISO、ExposureBiasValue、MeteringMode、Flash、WhiteBalance |
| 时间 | DateTimeOriginal / DateTimeDigitized（TIFF DateTime 同步）、OffsetTime* |
| 位置 | GPS 纬度、经度、海拔、拍摄朝向（ImgDirection） |
| 版权 | Artist、Copyright、ImageDescription |


## 2. 设备预设库

- 范围：iPhone 4 至 iPhone 17 系列全部机型（含 mini / Plus / SE / XR / e 系列 / Air），iPhone 18 Pro / Pro Max 和 iPhone Duo，以及带摄像头的全部 iPad（iPad 2 起，含 mini / Air / Pro）。
- 没有真机 EXIF 佐证的参数（如 iPhone 18 系列）标为“估算”，界面上会显示。
- 每台设备包含前置和全部后置镜头。
- 选中「设备 + 镜头」后自动填充：Make、Model、LensMake、LensModel、FNumber、FocalLength、FocalLengthIn35mmFilm。
- LensModel 按苹果真机格式生成，例如 `iPhone 15 Pro Max back triple camera 6.765mm f/1.78`。
- 数据存放在 App 内置的 `Devices.json`，新增机型只改数据不改代码。

## 3. 导入与格式

- 首页即相册：按相簿浏览，可滑动多选；长按照片放大预览（实况照片自动播放，带震动反馈）。另可从「文件」App 导入。
- 格式：JPEG、HEIC/HEIF、PNG，以及实况照片（图片和视频同步修改，保持配对）。暂不支持 ProRAW (DNG)。
- 写入使用 ImageIO `CGImageDestinationCopyImageSource`，只改元数据、不重新编码，画质零损失。
- 输出格式（设置）：默认“跟随机型”，所选机型能拍 HEIC 时输出 HEIC，否则转为 JPEG；也可选“保持原格式”。
- 匹配机型分辨率（设置，默认关闭）：打开后按所选镜头的像素尺寸重新缩放。
- 需要转格式或缩放时会以 90% 质量重新编码，其余情况无损。

## 4. 保存

- 保存方式（设置里选默认值，保存时可临时切换）：
  - A：另存为新照片，保留原图
  - B：另存为新照片后删除原图（系统弹窗确认）
- 另外支持导出到「文件」和系统分享面板。
- 新照片在相册里的拍摄时间和位置同步设置为编辑后的值。

## 5. 快速修改时间 / 地点

- 对相册中的照片直接修改相册层面的拍摄时间和位置（PHAssetChangeRequest），不生成新照片、不改文件内 EXIF。

## 6. 位置

- 地图点选或拖动大头针、搜索地名、使用当前位置、手动输入经纬度。
- 中国大陆范围内始终自动做 GCJ-02 ↔ WGS-84 转换（不提供开关）：地图显示用 GCJ-02，写入 EXIF 用 WGS-84。

## 7. MakerNote

- 提供「清除 MakerNote 及无关元数据」开关，默认关闭。

## 8. 批量修改

- 多选照片，统一套用同一组字段（每个字段可单独勾选是否修改，未勾选保持原值）。
- 时间两种模式：统一设为同一时间；整体平移（保留原先后顺序）。

## 9. 参数模板

- 把当前的字段组合保存为模板（名称 + 勾选的字段），单张或批量编辑时一键套用。

## 10. 收费

- 全部功能免费，无内购、无次数限制（2026-09-22 调整，原“专业版买断”方案已移除）。

## 11. 其他

- 首次打开显示功能介绍，之后可在设置里再次查看。
- 界面支持简体中文和英文，跟随系统语言；支持深色模式。
